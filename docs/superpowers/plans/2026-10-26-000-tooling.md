# 000 Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task, inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the Next.js app and enforce the tooling and quality checks in `specs/000-tooling.md`.

**Architecture:** Scaffold a current Next.js App Router project in a temporary directory, then merge its app and configuration files into this repository without replacing its existing documents. Layer the spec's formatter, type/test exclusions, editor settings, commit hook, and Sonar configuration on that base.

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, ESLint, Prettier, Vitest, Husky, lint-staged.

**Spec:** `specs/000-tooling.md`; `docs/superpowers/specs/2026-10-26-000-tooling-design.md`.

## Global Constraints

- Preserve `AGENTS.md`, `README.md`, `specs/`, `docs/`, and `design/` while merging the temporary scaffold.
- Use the exact scripts in the spec: `lint`, `format`, `format:check`, `typecheck`, `test`, and `check`.
- Exclude `design/magicpath/` from lint, format, typecheck, and tests; exclude `.next`, `node_modules`, and `coverage` from lint.
- Prettier settings: `semi`, `singleQuote`, `trailingComma: "all"`, `printWidth: 100`.
- Put `eslint-config-prettier` last in the flat ESLint configuration. Treat `console.log` as an error.
- Keep `.env*` ignored except `.env.example`; record variable names only and no values.
- Ask before installing any package not named by the spec, including any package proposed by the shadcn CLI.
- No CI, Supabase, Redis, product UI, disabled checks, hook bypasses, or unrelated changes.

## Review Focus

1. **Scaffold merge:** an existing project document must retain its content; Task 1 compares tracked files before and after.
2. **Prototype exports:** a syntactically invalid reference file under `design/magicpath/` must not change check results; Task 2 probes each tool's inclusion.
3. **Lint failure:** a temporary `console.log` must fail `npm run lint` and a commit; Tasks 2 and 3 probe this.
4. **Format failure:** a temporary badly formatted included file must fail `npm run format:check` and be corrected by `npm run format`; Task 2 probes this.
5. **Environment safety:** `.env.local` must be ignored while `.env.example` remains trackable; Task 3 checks `git check-ignore` and `git ls-files` after commit.
